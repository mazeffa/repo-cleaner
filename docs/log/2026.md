## 2026-09-18 (3) — Adversarial pass: 22 defects, none caught by the selfcheck

Decisions: D-007
Docs: CLAUDE.md, docs/DECISIONS.md, docs/DEFECTS.md, docs/log/2026.md

**What happened.** Everything shipped so far was verified against inputs chosen to pass:
the bundled selfcheck, one hand-built repo, and one banned-header commit. A pass built to
break it instead found 22 defects, four reproduced directly here. Two block use: the
checker crashes on any repo path containing a non-ASCII character, and it reports a missing
path for any backticked command carrying a flag — including the command this repo's README
tells users to run. The documented per-rule disable does not exist, so there is no way to
switch that off. The hook installed in this repo is mode 644, so its "blocks a bad commit"
claim holds on Windows only.

The selfcheck caught none of them, and that is structural: its fixtures are written by the
same hand as the rules, so each proves its rule can fire and none proves a rule stays quiet
when it should.
